## 📊 문제 상세

### 🔴 Issue #1: iOS 자정 넘김 (치명적)

**문제**: 23:50에 앱 켜고 자정 넘기면 어제 걸음수가 오늘에 합산됨

**예시**:
```
23:50 - 100보 걸음
00:00 - 자정 경과
09:00 - 3,000보 추가

표시값: 3,100보 ❌ (어제 100 + 오늘 3,000)
정상값: 3,000보 ✅
```

**원인**: `CMPedometer`의 `startOfDay`를 스트림 시작 시점에만 계산
**해결**: 자정 감지 타이머 추가 → 날짜 변경 시 스트림 재시작
**파일**: `ios/Runner/StepsStreamHandler.swift:14`

---

### 🟡 Issue #2: Android 재부팅 캐시 (높음)

**문제**: 폰 재부팅 후 앱 실행 시 1-2초간 이전 걸음수 표시

**예시**:
```
재부팅 전: 5,000보
재부팅 후 앱 실행: "5,000보" (1초) → "0보" (자동 수정)
```

**원인**: 캐시 읽을 때 센서 리셋 감지 안 함
**해결**: 캐시 검증 시 센서 값 비교 추가
**파일**: `android/.../StepsApi.kt:145`, `StepsForegroundService.kt:177`

---

### 🟢 Issue #3: Flutter monotonic 보정 (중간)

**문제**: 백그라운드에서 날짜 변경 시 걸음수 리셋 안 됨

**발생 조건**:
- 백그라운드 측정 ON 상태에서
- 앱을 종료하지 않고
- 자정 넘김

**원인**: 값 감소 방지 로직이 정상적인 리셋도 막음
**해결**: 날짜 변경 감지 시 리셋 허용
**파일**: `lib/features/steps/steps_provider.dart:84`
