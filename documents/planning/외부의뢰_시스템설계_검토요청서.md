## 1. 프로젝트 개요

### 1.1 서비스 소개
Walker홀릭은 걷기 기반 미션을 수행하면 지역 제휴 상점에서 사용 가능한 할인 쿠폰을 발급받는 O2O(Online-to-Offline) 건강 앱입니다.

### 1.2 핵심 기능
| 기능 | 설명 |
|------|------|
| **걷기 미션** | 10일 주기, 일일 5,000보 달성 시 1일 완료 처리 |
| **쿠폰 발급** | 미션 조건 충족 시 제휴 상점 할인 쿠폰 자동 발급 |
| **프리미엄 구독** | 월 990원, 쿠폰 금액 3배 + 월 3회차 미션 참여 |
| **친구 시스템** | 닉네임/초대코드 기반 친구 추가 |
| **초대 혜택** | 초대코드로 가입 시 30일 무료 프리미엄 |
| **지도** | 네이버 맵 기반 제휴 상점 표시 |

### 1.3 기술 스택
| 계층 | 기술 | 버전 |
|------|------|------|
| 프론트엔드 | Flutter (Dart) | 3.10.4+ |

## 4. 구독 비즈니스 로직

### 4.1 요금 체계
| 항목 | 무료 회원 | 프리미엄 회원 |
|------|-----------|---------------|
| 월 요금 | 0원 | 990원 (프로모션가) / 정상가 1,990원 |
| 쿠폰 할인 금액 | 500원 | 1,500원 (3배) |
| 쿠폰 최소 구매액 | 10,000원 | 15,000원 |
| 월 미션 참여 횟수 | 1회차 | 3회차 |
| 최대 월 혜택 | 500원 | 4,500원 (1,500원 × 3회) |

### 4.2 구독 흐름
```
[사용자] ─── 구독하기 클릭 ───→ [Google Play 결제 UI]
                                        │
                                   결제 승인
                                        │
                                        ▼
[in_app_purchase 플러그인] ── 영수증 검증 ──→ [Google Play Server]
        │
        │ 검증 완료
        ▼
[activateSubscription Cloud Function]
        │
        ├── users/{uid} 문서 업데이트
        │     ├── subscriptionStatus: "premium"
        │     ├── subscriptionExpiresAt: now + 32일
        │     ├── subscriptionPurchaseToken: 토큰
        │     └── subscriptionActivatedAt: 서버 시간
        │
        └── 반환: { ok: true, expiresAt: ISO-8601 }
```

### 4.3 현재 한계점 (검토 필요)

| # | 항목 | 현재 상태 | 위험도 |
|---|------|-----------|--------|
| 1 | **서버 측 영수증 검증** | in_app_purchase 플러그인 신뢰 (MVP) | 높음 |
| 2 | **결제 이력 저장** | 없음 (users 문서 덮어쓰기) | 높음 |
| 3 | **자동 갱신 확인** | 앱 진입 시 만료일 체크만 | 중간 |
| 4 | **Google Play RTDN** | 미구현 (Real-time Developer Notification) | 중간 |
| 5 | **환불 처리** | 미구현 | 중간 |
| 6 | **구독 필드 보호** | 클라이언트 쓰기 가능 (Firestore Rules) | 높음 |

## 6. 검토 요청 사항

### 6.1 DB 설계 검토
1. **users 문서 비대화**: 구독/미션/프로필 필드가 하나의 문서에 집중되어 있는데, 서브컬렉션 분리가 필요한가?
2. **payment_history 설계**: 위 제안 스키마가 분석/감사 용도로 충분한가?
3. **인덱스 설계**: 현재 복합 인덱스가 없는데, 쿼리 성능 관점에서 필요한 인덱스는?
4. **데이터 정합성**: cycleCompletedDays 배열 방식 vs 서브컬렉션 방식 장단점

### 6.2 구독 시스템 검토
1. **서버 측 영수증 검증**: Google Play Developer API 연동 방법 및 우선순위
2. **RTDN 구현**: Google Play Real-time Developer Notification 설정 가이드
3. **자동 갱신 처리**: 갱신 성공/실패 시 Firestore 업데이트 로직
4. **환불 대응**: Google Play 환불 시 구독 상태 자동 해제 로직
5. **구독 필드 보호**: Firestore Rules에서 subscription* 필드 클라이언트 쓰기 차단 방법

### 6.3 분석/운영 관점
1. **결제 대시보드**: payment_history 기반 매출/전환율 분석 쿼리 설계
2. **이상 감지**: 부정 사용(비정상 걸음 수) 탐지 로직 설계
3. **데이터 보존 정책**: 결제 이력 보존 기간 및 아카이빙 전략
4. **GDPR/개인정보**: 계정 삭제 시 결제 이력 처리 방침 (보존 vs 삭제)

### 6.4 확장성 검토
1. **iOS 대응**: Apple App Store 구독 연동 시 DB 스키마 변경점
2. **다지역 확장**: 남구 → 다른 지역 확장 시 places/coupons 구조 변경
3. **B2B 상점 관리**: 제휴 상점 관리자 포털 대응 시 데이터 구조
4. **쿠폰 정산**: 상점별 쿠폰 사용 정산 시스템 설계

## 7. Firestore Security Rules (현재)

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function isSignedIn() {
      return request.auth != null;
    }
    function isOwner(userId) {
      return isSignedIn() && request.auth.uid == userId;
    }

    // ── 사용자 문서 ──
    match /users/{userId} {
      allow read: if isOwner(userId);
      allow create: if isOwner(userId);
      allow update: if isOwner(userId)
        && (!('cycleCompletedDays' in request.resource.data)
            || !('cycleCompletedDays' in resource.data)
            || request.resource.data.cycleCompletedDays
               == resource.data.cycleCompletedDays);
      // ⚠️ subscription* 필드는 현재 클라이언트에서도 쓰기 가능
    }

    // ── 일별 걸음 수 ──
    match /users/{userId}/daily_steps/{dayKey} {
      allow read: if isOwner(userId);
      allow create, update: if isOwner(userId)
        && dayKey.matches('^[0-9]{4}-[0-9]{2}-[0-9]{2}$')
        && request.resource.data.steps is int
        && request.resource.data.steps >= 0
        && request.resource.data.steps <= 100000;
      allow delete: if false;
    }

    // ── 쿠폰 ──
    match /coupons/{couponId} {
      allow read: if isSignedIn();
      allow write: if false;
    }
    match /users/{userId}/coupons/{couponId} {
      allow read: if isOwner(userId);
      allow write: if false;
    }

    // ── 기타 (public_users, friends, fcm_tokens 등) ──
    // ... 생략 (별도 문서 참조)

    // ── 기본 거부 ──
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```

## 8. 현재 Cloud Functions 코드 핵심부

### 8.1 activateSubscription (구독 활성화)
```typescript
export const activateSubscription = functions
  .region("asia-northeast3")
  .https.onCall(async (data, context) => {
    const uid = requireAuth(context);
    const purchaseToken = String(data?.purchaseToken ?? "").trim();
    const productId = String(data?.productId ?? "").trim();

    if (productId !== "premium_monthly") {
      throw new functions.https.HttpsError("invalid-argument", "...");
    }

    const now = admin.firestore.Timestamp.now();
    const SUBSCRIPTION_DAYS = 32; // 30일 + 2일 유예
    const expiresAt = Timestamp.fromMillis(
      now.toMillis() + SUBSCRIPTION_DAYS * 24 * 60 * 60 * 1000
    );

    // ⚠️ 현재: payment_history 미기록
    await db.collection("users").doc(uid).set({
      subscriptionStatus: "premium",
      subscriptionProductId: productId,
      subscriptionPurchaseToken: purchaseToken,
      subscriptionExpiresAt: expiresAt,
      subscriptionActivatedAt: FieldValue.serverTimestamp(),
    }, { merge: true });

    return { ok: true, expiresAt: expiresAt.toDate().toISOString() };
  });
```

  .region("asia-northeast3")
  .https.onCall(async (data, context) => {
    const newUid = requireAuth(context);
    const code = String(data?.code ?? "").trim().toUpperCase();

    // 초대코드로 추천인 조회
    const q = await db.collection("users")
      .where("friendInviteCode", "==", code).limit(1).get();

    // 30일 무료 프리미엄 부여
    const newExtendedUntil = Timestamp.fromMillis(
      Date.now() + 30 * 24 * 60 * 60 * 1000
    );

    // 트랜잭션: 프리미엄 부여 + 양방향 친구 생성
    await db.runTransaction(async (tx) => {
      tx.set(newUserRef, {
        subscriptionFreeUntil: newExtendedUntil,
        subscriptionFreeSource: "referral",
        referredByUid: referrerUid,
        referredByCode: code,
        referredAt: FieldValue.serverTimestamp(),
      }, { merge: true });
      // + 양방향 friends 문서 생성
    });
  });
