| `subscription_cancel` | 구독 해지 | Google Play Real-time Developer Notification |
| `subscription_expire` | 구독 만료 | 만료 스케줄러 또는 앱 진입 시 확인 |

#### Flutter 클라이언트 모델

```dart
// lib/features/subscription/payment_history_model.dart

class PaymentRecord {
  final String id;
  final String type;         // subscription_new, renew, cancel, referral_grant
  final String productId;
  final int amount;
  final String currency;
  final String status;       // completed, refunded, pending
  final DateTime createdAt;
  final DateTime? expiresAt;
  final String source;       // google_play, referral, admin
  final String? note;

  String get typeLabel => switch (type) {
    'subscription_new'    => '프리미엄 구독',
    'subscription_renew'  => '구독 갱신',
    'subscription_cancel' => '구독 해지',
    'subscription_expire' => '구독 만료',
    'referral_grant'      => '초대 혜택',
    'refund'              => '환불',
    _                     => type,
  };

  String get amountLabel => amount == 0
      ? '무료'
      : '${NumberFormat('#,###').format(amount)}원';
}
```

#### Flutter Provider

```dart
// lib/features/subscription/payment_history_provider.dart

final paymentHistoryProvider = StreamProvider<List<PaymentRecord>>((ref) {
  final uid = ref.watch(authStateProvider).valueOrNull?.uid;
  if (uid == null) return Stream.value([]);

  return FirebaseFirestore.instance
      .collection('users').doc(uid)
      .collection('payment_history')
      .orderBy('createdAt', descending: true)
      .snapshots()
      .map((snap) => snap.docs.map(PaymentRecord.fromDoc).toList());
});
```
